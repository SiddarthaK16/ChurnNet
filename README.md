# 🧠 ChurnNet — Customer Churn Prediction with ANN

A deep learning project that uses an **Artificial Neural Network (ANN)** to predict whether a bank customer is likely to churn.

This project was built as my **first hands-on neural network project**, covering the complete workflow from data preprocessing and model training to inference and deployment with Streamlit.

---

## 🚀 Demo

The application allows users to enter customer information and receive:

- 📊 Churn probability
- 🔴 Likely to churn / 🟢 Not likely to churn prediction
- Interactive inputs through a Streamlit web interface
